# Legacy AI Studio migration draft

**Do not use this directory for live PostgreSQL/PostGIS creation.**

These SQL files were generated by the initial AI Studio prototype and represent a simplified/reworked schema. They are retained temporarily for diff/history while the prototype is reconciled.

The authoritative migration chain is:

`db/migrations/0001_extensions_enums.sql` → `db/migrations/0010_first_party_activity.sql`

`src/migration_runner.ts` reads `db/migrations` exclusively.

After the reconciliation PR is stable, this legacy directory can be deleted in a follow-up cleanup; Git history will preserve it.
